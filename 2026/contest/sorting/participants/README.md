# Участники конкурса по сортировке

Чтобы участвовать, добавьте сюда файл `<ник>.md` через pull request.

- Ник: латинские буквы, цифры, дефис; до 20 символов. Он будет в таблице результатов.
- В файле — одна строка: ваш GitHub-аккаунт, например `@octocat`.
- Pull request должен быть от этого же аккаунта.
